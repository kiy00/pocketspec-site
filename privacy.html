プライバシーポリシー

最終更新日: 2026年7月10日

本ポリシーは、iOS アプリ「PocketSpec」（以下「本アプリ」）における利用者の情報の取り扱いについて定めるものです。

1. 基本方針

本アプリは、GitHub リポジトリ内の Markdown 仕様書を閲覧するための Read Only ビューアです。 本アプリは独自のサーバーを持たず、利用者の情報を運営者（開発者）のサーバーへ送信・収集することは一切ありません。

2. 取得・保存する情報

本アプリは、利用者が本アプリを利用するために、以下の情報を利用者の端末内にのみ保存します。

  • GitHub アクセストークン：GitHub へのログイン（OAuth Device Flow）または利用者が入力した Personal Access Token。iOS の Keychain にのみ安全に保存され、外部へ送信されません。
  • プロジェクト設定：閲覧対象の GitHub リポジトリ名・ブランチ・ドキュメントルート・表示名などの設定情報。 端末内のアプリ領域に保存されます。
  • ローカルキャッシュ：取得した Markdown・画像・ファイル一覧などを、オフライン閲覧のため端末内に保存します。

3. 情報の送信先

本アプリが通信を行う相手は、利用者自身が設定した GitHub（github.com / api.github.com） のみです。 GitHub との通信は、仕様書ファイルの取得およびログイン認証のために行われ、GitHub のプライバシーポリシーが適用されます。

  • GitHub Privacy Statement: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement

本アプリは、利用者の情報を運営者や第三者（広告・解析事業者等）へ送信しません。広告 SDK・アクセス解析ツール・トラッキング機能は一切含みません。

4. 権限（GitHub App）

本アプリが GitHub に要求する権限は、仕様書の閲覧に必要な最小限のもの（Contents: 読み取り専用、Metadata: 読み取り専用）に限定されます。 ファイルの編集・作成・削除は行いません。

5. 情報の削除

保存された情報は、以下の操作でいつでも削除できます。

  • ログアウト：Keychain 内のアクセストークンを削除します。
  • プロジェクト削除：該当プロジェクトの設定とローカルキャッシュを削除します。
  • 本アプリのアンインストール：本アプリが端末内に保存したすべての情報が削除されます。

6. 子どものプライバシー

本アプリは特定の年齢層を対象としたものではなく、個人を特定する情報を収集しません。

7. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。変更後の内容は本ページに掲載した時点で効力を生じます。
