PocketSpec サポート

最終更新日: 2026年7月10日

「PocketSpec」は、GitHub リポジトリ内の Markdown 仕様書を iPhone で快適に読むための Read Only ビューアです。 ご不明な点・不具合のご報告は、以下の窓口までお寄せください。

お問い合わせ

不具合のご報告・ご要望は、お問い合わせフォームからお寄せください。

  • お問い合わせフォームを開く

ご報告の際は、iOS のバージョン・端末機種・発生した操作手順を添えていただけると対応がスムーズです。

よくある質問

ログインできません / ログインボタンが押せません

GitHub App の設定が必要です。しばらくしても解決しない場合は、上記のフォームからお問い合わせください。

「このリポジトリにアクセスできません」と表示される

対象のリポジトリに GitHub App がインストールされていないか、権限が不足している可能性があります。 対象リポジトリへのインストール状況をご確認ください。

「リポジトリ・ブランチ・docRoot が見つかりません」と表示される

プロジェクト設定の owner / repo・ブランチ・ドキュメントルートのパスをご確認ください。

オフラインでも読めますか？

一度取得した仕様書は端末内にキャッシュされ、オフラインでも最後に同期した内容を閲覧できます。
